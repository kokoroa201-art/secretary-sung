4재사용 가능한 작업 패턴
🗂️ 데이터 → 대시보드
CSV/TXT 파일을 읽어 데이터를 추출 → HTML 카드 레이아웃으로 시각화.
요청 예시: "○○-데이터 폴더 읽어서 dashboard.html 만들어줘. 섹션은 [A, B, C]로."
📈 데이터 → 순수 SVG 차트
CSV 집계 후 외부 라이브러리 없이 SVG로 선/막대/원형 그래프 구현. 호버 툴팁 포함.
요청 예시: "○○.csv로 chart.html 만들어줘. 외부 라이브러리 없이."
🔄 프로세스 → SVG 다이어그램
단계별 플로우를 SVG로 직접 생성. 크기·색상·단계 수 조절 가능.
요청 예시: "A→B→C→D 4단계 플로우를 diagram.svg로 만들어줘. 크기 600×150px."
🔍 URL → 분석 리포트
브라우저로 사이트 실시간 접속 → 구조/기능/디자인 분석 → 카드형 HTML 리포트 생성.
요청 예시: "https://example.com 분석해서 report.html 만들어줘."
✨ 디자인 업그레이드 패턴
기존 HTML에 글래스모피즘(backdrop-filter:blur), 그라디언트 배경, 다크/라이트 토글(localStorage) 적용.
요청 예시: "dashboard.html을 글래스모피즘 + 다크모드 토글로 업그레이드해줘."
🗂️ 파일 자동 분류
폴더 안 파일들의 내용을 읽어 카테고리를 판단 → 하위 폴더 생성 후 자동 이동.
요청 예시: "○○ 폴더 파일들을 [카테고리A, B, C]로 분류해줘."
🚀 GitHub + Vercel 배포
.env에 토큰 저장 → git init → .gitignore에 .env 추가 → 파일 커밋 → push → Vercel 자동 배포.
주의: index.html 반드시 포함해야 Vercel 루트(/) 404 방지.
